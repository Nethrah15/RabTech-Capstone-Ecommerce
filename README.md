GitHub: https://github.com/Nethrah15/RABTECH-Capstone-Ecommerce

## Architecture
Frontend (HTML/CSS/JS) -> api.js (FakeStoreAPI) -> localStorage (Persistent State)

## Features
- Auth Simulation: Login with name, saved in localStorage
- Interactive Catalog: Real products from FakeStoreAPI
- Dynamic CRUD: Add / Edit / Delete your own products
- Search, Category Filter, Price Sort (no reload)
- Cart: Add to cart, Total, Clear, persists after refresh
- Responsive: Mobile-first Grid + Glassmorphism + Dark-ready Tokens

## How to Run Locally
1. Clone repo
2. Open with Live Server / VS Code
3. Or open index.html

## Tech Stack
HTML, CSS, JavaScript (ES Modules), Fetch API, localStorage, FakeStoreAPI
